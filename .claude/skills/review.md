# Self-review skill

## 리뷰 규칙

- `git diff origin/main...HEAD`를 실행하여 변경 사항을 확인한다.
- 변경/추가된 코드를 중심으로 리뷰하되, 주변 코드의 패턴·컨벤션·네이밍과 일관성이 맞는지도 확인한다.
- 한국어로 작성한다.
- 파일 이름과 줄 번호를 명시한다.
- 문제가 없으면 "리뷰 결과 문제가 발견되지 않았습니다."라고 명시한다.
- 코드 블록이나 JSON으로 감싸지 않는다.
- 마지막에 "✅ 리액션이나 피드백을 주세요."를 추가한다.
